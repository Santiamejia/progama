¿Qué es HTML?

HTML (HyperText Markup Language) es el lenguaje que permite estructurar el contenido de una página web, organizando títulos, párrafos, enlaces, listas e imágenes de manera clara y ordenada.

¿Qué es CSS?

CSS (Cascading Style Sheets) se utiliza para dar estilo a las páginas web, definiendo colores, tamaños, márgenes y posiciones. También permite crear diseños consistentes y añadir efectos visuales como transiciones y animaciones.

Estructura básica de una página web

La estructura básica de una página web incluye etiquetas como <html>, <head> y <body>. El contenido visible se coloca dentro del <body>.
